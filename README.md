# Telegram Multi-Account Bot Manager

بوت تليجرام متقدم لإدارة حسابات متعددة مع نظام تحويل ورد تلقائي سريع جداً.

## المميزات الرئيسية

- ✅ **تحكم كامل عبر بوت تليجرام** - كل شيء يُدار من خلال أوامر البوت
- ✅ **إضافة حسابات لا محدودة** - أضف أي عدد من حسابات التليجرام
- ✅ **سرعة فائقة** - معالجة مئات الرسائل في الثانية باستخدام worker pools
- ✅ **نظام كوت ذكي** - حظر تلقائي للمستخدمين المتكررين
- ✅ **كلمات مفتاحية متقدمة** - مطابقة ذكية مع fuzzy matching
- ✅ **ردود تلقائية دوارة** - رسائل متنوعة تتناوب تلقائياً
- ✅ **إحصائيات مباشرة** - تتبع الأداء في الوقت الفعلي
- ✅ **نسخ احتياطي واستعادة** - حفظ واسترجاع الإعدادات
- ✅ **حماية من الفيض** - rate limiting ذكي

## المتطلبات

- Python 3.8+
- pip
- Telegram Bot Token
- Telegram API ID و API Hash (من my.telegram.org)

## التثبيت السريع

```bash
# 1. نسخ الملفات
cd telegram_bot

# 2. إعداد البيئة
pip install -r requirements.txt

# 3. إعداد الإعدادات
cp .env.example .env
# عدل ملف .env بمعلوماتك

# 4. التشغيل
python main.py
```

## ملء ملف .env

```env
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
API_ID=YOUR_API_ID
API_HASH=YOUR_API_HASH
OWNER_ID=YOUR_TELEGRAM_USER_ID
WORKERS=50
SEND_CONCURRENCY=50
QUEUE_SIZE=10000
DB_PATH=bot_data.db
```

## الأوامر المتاحة

### إدارة الحسابات

| الأمر | الوصف | الاستخدام |
|-------|-------|----------|
| `/addaccount` | إضافة حساب جديد | تفاعلي - 4 خطوات |
| `/accounts` | عرض الحسابات | `/accounts` |
| `/startacc` | تشغيل حساب | `/startacc +966XXXXXXXXX` |
| `/stopacc` | إيقاف حساب | `/stopacc +966XXXXXXXXX` |
| `/delacc` | حذف حساب | `/delacc +966XXXXXXXXX` |
| `/setmode` | تعيين الوضع | `/setmode +966XXXXXXXXX both` |
| `/settarget` | تعيين الهدف | `/settarget +966XXXXXXXXX -100XXXXXXXX` |

### أنماط التشغيل (Modes)

- `forward` - تحويل الرسائل فقط
- `reply` - رد تلقائي فقط
- `both` - تحويل + رد تلقائي (افتراضي)
- `self` - للاختبار

## كيفية الإضافة

### إضافة حساب جديد:

1. أرسل `/addaccount`
2. أدخل API ID
3. أدخل API Hash
4. أدخل رقم الهاتف
5. أدخل معرف مجموعة الهدف

### التوثيق (إذا لزم):

```
/startacc +966XXXXXXXXX
```

البوت سيرسل كود التحقق. أرسله باستخدام:
```
/verify +966XXXXXXXXX 12345
```

## منطق التشغيل

1. **المعالجة**: عند وصول رسالة إلى أي مجموعة:
   - التحقق من الكلمات المفتاحية
   - تجاهل الرسائل الطويلة (>17 كلمة)
   - تجاهل الروابط والمنشنات
   - تجاهل المستخدمين المحظورين

2. **التحويل**: إذا تطابقت الكلمات:
   - تحويل الرسالة لمجموعة الهدف
   - تسجيل العملية

3. **الرد التلقائي**: إذا تطابقت مع محفز:
   - إرسال الرسالة الأصلية كـ DM
   - إرسال رد تلقائي بعدها
   - تسجيل العملية

4. **الحماية**: بعد 4 ردود لنفس المستخدم في 24 ساعة:
   - حظر تلقائي للمستخدم
   - إيقاف الردود له

## الأداء والسرعة

- **Worker Pools**: 50 عامل متوازي
- **Queue Processing**: معالجة غير متزامنة
- **SQLite**: قاعدة بيانات خفيفة وسريعة
- **Caching**: تخزين مؤقت للإداريين
- **Deduplication**: منع المعالجة المكررة
- **Rate Limiting**: حماية من الإفراط
